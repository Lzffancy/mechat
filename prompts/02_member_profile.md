# 02 · 成员画像

## 用途

把指标表和一二十条代表发言，写成一段人话。指标能说明"问句率 23%、短句率 47%"，说明不了
"他在群里负责什么"，这一层只能读原文。

## 输入

```bash
# 指标 + 粗标签
python -m wxchat_analysis profile --input 群.jsonl --top 15

# 该人的代表发言（带上下文，pad 给 3~5 条就够，看多了会被单次情绪带偏）
python -m wxchat_analysis ctx --input 群.jsonl --who 某人 --pad 4 -o 某人.txt
```

代表发言要**按类型各取几条**，不要只取最长的：一条话题发起、一条被多人回复的、一条情绪化
的、一条纯信息型的、一条玩笑。只给长发言会得到一个"爱讲道理"的人设，和真实印象差很远。

## 提示词正文

```text
下面是一个群成员的行为指标和代表发言。请写一段人物卡。

指标（全部是可数的行为，不是评价）：
{{profile 命令输出的这一行，含 msgs / share / active_days / avg_len / short_ratio /
 emoji_per100 / q_per100 / feel_per100 / comfort_per100 / abstract_per100 / joke_per100 /
 init_per1000 / buckets}}

群基线（用来对照，别孤立看指标）：
{{群整体同名指标}}

他的主题偏好（与群基线比，lift > 1.3 才算偏好）：
{{topic 偏好片段}}

代表发言：
{{ctx 输出，40~60 条，带索引}}

写作要求：

1. 四段，每段 2~3 句，总长 150~250 字。不要小标题，不要分点。
2. 每段一个主题，顺序固定：
   一、他在群里主要做什么（发起、接话、提供信息、消化情绪，四选一为主，用数字支撑）
   二、他怎么说话（句长、语气、爱用什么词，引 2 条原话，原话用「」括住）
   三、他关心什么（用主题 lift 和代表发言互证，lift 不到 1.3 的主题不要提）
   四、如果数据显示前后期有变化（发言量、时段、主题），写一句；没有就写"没有明显变化"
3. 引原话时保留原样，不改标点以外的任何字。
4. 不确定的不写。指标看不出的事（职业、年龄、婚姻状况）除非他自己说过并给出索引，否则不提。

禁止：

- 心理诊断："回避型依恋""内在小孩""控制欲强"——这是在给真人贴病历。
- 性格形容词堆砌："他很幽默、很温暖、很有思想"。要么给证据要么不写。
- 评价外貌、道德、能力。
- 把个别发言当成人设："他喜欢足球"如果只说过一次，不能这么写。
- 用"值得注意的是他……""更难得的是……"这类路标句。

输出纯文本，四段，段间空一行。不要在开头写"这是某某的人物卡"。
```

## 验收

- 四段都在，不超 250 字；
- 至少 2 处引了原话，且能在输入里找到；
- 没有任何一条判断找不到对应指标或原话。

## 已知失败

- **写成夸奖**。模型天然偏正面，会给每个人都写"热心、有趣、有见地"。要求它写"做什么"
  而不是"怎么样"，能压掉一部分。
- **拿指标当结论**。"他问句率 23%，说明他善于思考"——问句率高也可能只是爱抬杠。
  指标只能支撑"他常提问"，不能支撑"他善于思考"。
- **对沉默成员硬写**。发言少于 100 条的人给不出画像，直接输出"样本不足以画像，
  累计 N 条，集中在这几个月"，不要凑字数。

## 下一步

四段卡片直接进报告的人物版面，也可以在 `04` 里作为背景素材。同一个人不要重复画像——
报告里出现两版互相矛盾的描述，读者只会信第一版。
